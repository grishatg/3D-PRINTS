# Fonts

`Inter-Bold.ttf` is used for the A·B initials (`FONT` in `src/v7.py`). It is a static Bold instance of Inter, from Google Fonts.

The details below are taken from the font file's own name table:

- **Copyright:** Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter)
- **Version:** Version 4.001;git-66647c0bb
- **Licence:** SIL Open Font License, Version 1.1 (no description string is embedded in this build; the URL below is the one embedded in the font)
- **Licence URL:** https://openfontlicense.org

The SIL Open Font License 1.1 permits bundling and redistribution alongside software.
